# Aplicație de Gestionare a Notelor Studenților

Această aplicație permite profesorilor și studenților să gestioneze notele într-un mod eficient. Utilizatorii pot adăuga, vizualiza și modifica notele, precum și genera rapoarte pentru performanța academică.

## Funcționalități
- **Adăugarea notelor**: Profesorii pot adăuga note pentru fiecare student.
- **Vizualizarea notelor**: Studenții pot vizualiza notele lor într-un format ușor de înțeles.
- **Modificarea notelor**: Profesorii pot modifica notele aferente studenților.
- **Generarea rapoartelor**: Rapoarte detaliate despre performanța studenților sunt disponibile pentru analiză.

## Instalare
1. Clonați repository-ul: `git clone https://github.com/deliasascau/student-grade-app.git`
2. Navigați în directorul aplicației: `cd student-grade-app`
3. Instalați dependențele necesare.

## Utilizare
1. Lansați aplicația folosind comanda specifică.
2. Urmați instrucțiunile de pe ecran pentru a gestiona notele studenților.
